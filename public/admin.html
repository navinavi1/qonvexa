POLICY ENGINE

Autonomy limits

t2000 Open Jobs are filtered separately: default minimum $35, priority $65+, premium $100+. Already-assigned seller-queue work is not discarded after claim; AutonomOS finishes obligations it has already accepted.

Fast claim poll only re-checks Clawlancer/t2000 open listings — it does not redo treasury/offer/competition work, so it can safely run much more often than the full heartbeat.

Required for Firecrawl/E2B to actually run: even with the toggles above set correctly, every paid tool call (web_search, web_scrape, run_python) is also checked against this ceiling — it defaults to $0, which silently blocks all of them regardless of the toggles. Set it above your expected per-call cost (e.g. 0.05) to actually let agents spend.

Seed budget is the one-time head start (before any revenue) that lets Earned-funds-only mode take the first jobs at all — without it, a brand-new deployment with $0 revenue can never afford its first paid job.

Precedence: Zero-spend wins if on. Otherwise Earned-funds-only (default) caps spend to money AutonomOS has actually already earned. Unrestricted only applies once both of the above are off.
