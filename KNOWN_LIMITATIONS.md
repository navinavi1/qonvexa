# Known limitations — production blockers

1. **Live implementation is NOT implemented.** Every catalogue service has `liveExecutorAvailable=false`; preflight never sells unsupported work. Quotes are estimates/review requests, not purchasable implementation offers. Payment collection for implementation is absent. Plan/approval/fixture QA cannot be presented as delivery.
2. **CRM OAuth lifecycle and Access onboarding are incomplete.** Pipedrive/Zoho have limited fixture-tested official read probes, not OAuth app registration, token exchange/refresh/revocation, plan discovery, workflows or live writes. WordPress user read does not detect builder/theme/plugins, backup/staging or prove safe editing. Connection endpoint explicitly returns 501; UI does not ask for passwords.
3. **Audit coverage is partial.** Twenty module categories exist, but only static/public checks produce evidence. No rendered mobile interactions, screenshot capture, Lighthouse/CrUX, LCP/INP/CLS, unused JS/CSS, measured contrast, live form delivery, real CRM flow, review process, authenticated update checks or e-commerce purchase tests. Local facts/business claims need customer verification. Robots/sitemap status is captured but a full robots evaluator, sitemap parser and comprehensive broken-link crawler are absent. No Google ranking/AI visibility measurement.
4. **Analytics is a plan/interface, not a working integration.** No GA4/GTM/GSC OAuth or deploy; no correlated provider event receipt demonstrated. The receipt predicate is an adapter contract, not proof that a real event was received.
5. **Safe defaults intentionally stop public scanning/payments.** Without opting in and starting the worker, a request shows review required. This is an honest operational state, not silent completion. Automated support fulfillment/email recovery is absent. Use mock tests, not real credentials, for the delivered package.
6. **Single-host persistence.** New SQLite WAL is on the same local disk for web/worker; existing business records stay JSON/NDJSON. A separate Render worker cannot share the web disk automatically. Distributed replicas, horizontal scaling, SQLite backup automation and volume-load testing are not implemented. Historical render.yaml is not a validated new deployment blueprint.
8. **Outreach is draft-only.** No discovery/search provider, sending, bounce/reply integration, mass send, deliverability system or legal certification. Country rules are conservative project configuration, not complete statutory analysis. The opt-out path and suppression are implemented; supplied business source/relevance/identity still require human review.
9. **No autonomous AI agent is used in the audit.** Deterministic facts only. Knowledge entries require approval and the responder uses exact approved answers, otherwise handoff. Retrieval/chat/widget deployment/booking/lead collection are not implemented.
10. **QA/rollback are fixture-validated architecture.** No site backup provider, staging provisioning, production rollback or external email receipt test. Snapshot objects in the fixture runner are not production website backups. Medium/high risk approval and ambiguous state handling are tested, not proof of real-provider reliability.
11. **Cost accounting is incomplete for live operations.** Scan worker reserves projected compute; actual costs stay unknown unless settled. No live LLM/search/email billing integration, refund engine or gross-margin reconciliation. Small/large caps are configured but not consumed by nonexistent live executors.
12. **Privacy/retention operational steps remain.** Run/schedule cleanup after backup; no automatic cleanup scheduler. Local disconnect does not guarantee provider-side revocation. New sessions expire after configured retention and require staff help thereafter. Raw HTML not stored; legacy lead/order retention is unchanged.
13. **UI validation was local HTTP + JSDOM**, not a rendered mobile/desktop browser, assistive-technology audit or production load test. Admin has new review views and legacy secure-link action; full quote editing/service toggles/implementation pause UI is not completed.
14. **Legacy test limitation.** The unchanged `dashboard-truth-test.mjs` fails in BOTH the original extracted project and this release on crypto-only refusal visibility. This is disabled AutonomOS behavior, left untouched per scope. Coding-job test contains a git commit and is skipped under the explicit no-commit rule; initial guarded attempt blocked it before execution. No test was deleted.
15. **Potentially paid legacy resources may still bill externally** even though no workers start here. This work does not cancel any service/subscription. See PAID_SERVICES_AUDIT.md; owner must decide separately.

No new TODO/FIXME stubs are used as production features. Incomplete functions have explicit unavailable/status boundaries; legacy TODOs remain outside the active runtime. This ZIP is a substantial local foundation, not the complete 163-point production product.

Financial JSON storage supports one web instance. Bank receipt verification is manual. Historical order records retain their previous access and delivery semantics.
